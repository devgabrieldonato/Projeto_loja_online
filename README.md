# Basic Shop

Projeto de loja on-line desenvolvido com HTML, CSS e JavaScript. A aplicação apresenta uma vitrine de produtos, filtros, carrinho de compras e fluxo de checkout.

## Deploy

Acesse o projeto publicado em:

[https://projeto-loja-online-six.vercel.app/](https://projeto-loja-online-six.vercel.app/)

## Funcionalidades

- Vitrine de produtos da Basic Shop.
- Filtros por produto e cor.
- Carrinho de compras com itens adicionados e subtotal.
- Página de checkout para finalizar o pedido.
- Formulário com dados pessoais e endereço de entrega.
- Consulta de CEP e cálculo estimado de frete.
- Aplicação de cupom de desconto.
- Confirmação do pedido e avaliação da experiência.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Vercel

```text

├── checkout.js
├── filters.js

```

## Como Executar Localmente

1. Clone este repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Navegue pela loja, adicione produtos ao carrinho e acesse o checkout.
